Cómo usar esta demo · instrucciones
  1. La vista Semana es la vista principal. Usa Mes o Día para ampliar o reducir el periodo; la agenda semanal por horas siempre está disponible.
  2. Selecciona un espacio horario para crear una cita o usa “Nueva cita”.
  3. Administra personas, requirientes o empresas desde el panel lateral. Cambia el término con el botón superior.
  4. Usa 🎨 Tema para recorrer los esquemas de color.
  5. 💾 Guardar JSON descarga una copia de citas y personas. Importar JSON restaura una copia.
  6. ▤ PDF abre la impresión del calendario; elige “Guardar como PDF”.
  7. El ZIP incluye esta demo. Se necesita internet para cargar FullCalendar y el catálogo de servicios; los datos se guardan localmente.

Demo con datos ficticios. No es una ficha clínica ni debe almacenar datos sensibles. Conserva tus copias JSON.
