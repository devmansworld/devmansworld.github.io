First tester mission: Agenda Two

We are bringing back the demo with fictional people loaded automatically. When that edition is published, use this checklist:

  1. Open the demo and confirm the fictional sample people appear.
  2. Create a test person using obviously fictional information.
  3. Create an appointment and associate it with that person.
  4. Edit the appointment, then cancel or delete it if those actions are available.
  5. Refresh the page and check whether the data behaves as expected.
  6. Try the language selector, theme controls and mobile layout where available.
Testing safety: Use fictional information only. Do not enter real patient details, passwords, API keys or other private data. These prototypes are demos, not production clinical or payment systems.

How to report a finding

When something feels wrong, include the demo name, browser/device, steps to reproduce, what you expected, what happened, and a screenshot if useful. Please remove personal information from screenshots.
