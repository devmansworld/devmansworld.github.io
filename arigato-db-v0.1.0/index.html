ARIGATO DATABASE BRIDGE

Version 0.1.0 · Isolated backend experiment

Not deployed. This branch contains backend source code. GitHub Pages cannot run the Python API. The API must be deployed separately to a secure host.

Architecture

Static ARIGATO frontend → HTTPS FastAPI service → persistent PostgreSQL database.

Included

  • SQLModel models for people, appointments and payments
  • Token-protected payment history and registration endpoints
  • Monthly cashflow grouped by currency
  • SQLite for local development; PostgreSQL for remote deployment
  • Environment-based configuration and CORS origin allowlist

Important migration rule

Existing browser localStorage remains intact. No automatic dual-write or destructive migration is enabled. We will add an explicit adapter and reconciliation workflow before connecting the production agenda.

Source and setup

See README.md and the app/ directory in the repository. Copy .env.example to .env, configure a private token, install the project and run Uvicorn for local development.
